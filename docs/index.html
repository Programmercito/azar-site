LA CIENCIA DEL CAOS CONTROLADO

A diferencia de los generadores pseudo-aleatorios (PRNG) convencionales que dependen de una semilla estática, Azar implementa un sistema de Entropía Adaptativa.

Nuestro motor no solo genera números; captura la micro-variabilidad del entorno digital y humano para crear un flujo de datos impredecible que es, por definición, irreproducible.

PHASE_01

MUESTREO DE JITTER

Capturamos las fluctuaciones de microsegundos entre los frames de renderizado (RAF). Este "ruido térmico digital" es único para cada CPU y carga de trabajo actual.

PHASE_02

ENTROPÍA HUMANA

Cada píxel que recorres con tu ratón o cada toque en pantalla inyecta datos de 32 bits en nuestro pool. Tu sistema motor es la fuente de entropía más pura.

PHASE_03

MEZCLA XORSHIFT

Los datos recolectados se someten a un algoritmo de mezcla XOR-Shift-Add, redistribuyendo la densidad de bits para eliminar cualquier patrón estadístico.

PHASE_04

FUSIÓN CRIPTOGRÁFICA

Finalmente, combinamos el pool humano con el crypto.getRandomValues() nativo, garantizando seguridad criptográfica de nivel militar.
